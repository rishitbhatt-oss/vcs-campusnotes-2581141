# CampusNotes

CampusNotes is a simple repository for organizing
and maintaining academic notes for university students.

## Features
- Subject-wise note organization
- Reusable note templates
- Simple Markdown-based documentation

## Project Structure

campusnotes/
├── notes/
├── templates/
├── README.md
└── .gitignore

## Getting Started

Clone the repository:

git clone <repository-url>

Open the project folder and browse the notes.
